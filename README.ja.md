# ShakaPachi

[English](README.md) | **日本語**

macOS のウィンドウスイッチャー。Cmd を押したまま Tab でウィンドウを選び、Cmd を離すと
そのウィンドウがアクティブになる。

公式サイト: <https://senchan-company.com/shakapachi/>

## 特徴

- アプリアイコン、ウィンドウタイトル、選択中のライブプレビュー
- 表示単位: 「ウィンドウ単位」はフラットな一覧、「アプリ単位」はアプリ間を移動し 1 つを最大 3 枚のプレビューに展開
- 並び順: 最近使った順 (MRU)、アプリ別、最近使ったアプリ順
- トリガー: Command / Option / Control と、Tab またはグレイヴキー
- ホバーで前面化: カーソルを載せたまま 0.4 秒待つとそのウィンドウが前に出る (既定 OFF)
- メニューバー常駐、Dock アイコンなし
- テーマ、アクセントカラー、利用統計

既定値は Cmd+Tab、ウィンドウ単位、最近使った順、プレビューオン、現在の Space のみ。

## 動作要件

- macOS 13 Ventura 以降
- アクセシビリティ権限(イベントタップ、ウィンドウの前面化)
- 画面収録権限(ウィンドウタイトル、ライブプレビュー)

## ビルド

```
make run
```

`ShakaPachi.app` をビルドし、署名して起動する。
